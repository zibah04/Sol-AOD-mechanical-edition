# Sol — Mechanical Edition

A premium, minimalist native Xiaomi theme led by a mechanical Always-On Display, beginning with the **Redmi Note 10 running MIUI 12.5.5**.

## Approved design direction
- Pure-black AMOLED background.
- Oversized mechanical dial on the left, intentionally cropped beyond the screen edge.
- Restrained graphite-grey rings and mechanical markings.
- Large champagne-gold hour digits (#C6A15B).
- Matching gold minute capsule with curved minute numerals around the dial.
- Correct live weekday and date.
- Battery indicator, charging-state design and system notification icons.
- Matching lock screen, wallpapers, icons and supported system styling.
- Portrait AOD is primary; landscape bedside layout remains a separate future exploration.

## Target device
- Redmi Note 10 (sunny)
- MIUI 12.5.5 (V12.5.5.0.RKGMIXM)
- Android 11
- 1080 × 2400
- No root access intended

## Repository layout
- aod/ — native Xiaomi MAML AOD source and metadata
- assets/source/ — editable original artwork and source files
- assets/previews/ — device previews and screenshots
- docs/ — design, compatibility and publishing documentation
- theme/ — full Xiaomi theme integration (to be built and exported with Xiaomi's supported editor)

## Status
**Early production / validation stage.** The repository contains the first MAML layout prototype and AOD metadata. These are source files, **not a finished installable or upload-ready theme package**. The MAML must be validated in Xiaomi's editor, corrected, exported, and tested on the target phone. Matching lock-screen, wallpaper, icon and system resources and copyright evidence are still required.

## Store publishing
The intended release is free under the name **Sol Mechanical Edition**, subject to designer registration and Xiaomi review. Follow [the Xiaomi Store submission guide](docs/XIAOMI-STORE-SUBMISSION.md) and re-check the official requirements before upload.
